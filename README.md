# 掌中榫局 · Hand Gesture Luban Lock

基于浏览器摄像头手势识别与 Three.js 的鲁班锁空间解谜游戏。

## 核心玩法

- 食指指向构件，捏合完成抓取
- 移动手掌，沿榫木方向抽出活榫
- 张开手掌释放构件
- 未抓取时张开手掌并转动手腕，旋转整个观察视角
- 按正确顺序拆解六根榫木，完成鲁班锁解密

## 运行

直接打开 `index.html`，或使用静态网页服务器运行。首次使用手势操作时，请允许浏览器访问摄像头。

页面通过 CDN 加载 Three.js 与 MediaPipe Hands，因此需要联网。

## 鼠标操作

- 点击并拖动构件：抽取榫木
- 拖动空白区域：旋转观察视角
- 滚轮：调整观察距离
