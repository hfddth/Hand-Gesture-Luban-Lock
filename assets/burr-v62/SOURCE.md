# 三通关卡模型来源与范围

- 来源：用户提供“三通.zip”，含一个 SOLIDWORKS 装配体与三个零件。
- 使用本机 SOLIDWORKS 2024 强类型 API 只读打开本地导入副本，将三个零件导出为 STL，记录装配体的构件变换；未改写原压缩包或用户源文件。
- `santong-model.json` 保留导出网格与装配位置，转换为网页坐标后统一居中缩放。不是用三个简单方块代替提供的模型。
- 原尺寸约 30×30×30mm；三构件三角面数量分别为 40、36、40。
- 木纹与颜色使用项目现有材质重新赋予，三个零件有适度色差。
- `santong-preview.webp` 为本地运行场景截图，不是另生成的结构示意图。
- 原始 CAD、STL 与装配矩阵仅保留在本地 `imports/santong-v62/`，不作为网页运行依赖。

当前交付是关卡 UI 与真实模型展示，包含构件选择、提示、观察旋转、暂停与既有摄像头选取适配。没有据此宣称已实现该三通结构的真实拆解约束或通关规则；这些仍需后续设计与验证。
