# 抓取旋转视觉板块接入

用户提供「抓取旋转视觉板块.zip」。抓取控制器与现用 recognition-v33/pinch-controller.mjs 的 SHA256 相同：77dc9a8597fcfc803625eae2acc8d8b2b07a2039e5d674460ae14bd62b3692cd。直接复用该控制器、原阈值及手掌姿态映射。

应用适配器将抓取页与旋转页合并：明确张掌100ms进入整体旋转；保持条件为至少2指伸展、捏合比高于0.3；收拢400ms退出，退出250ms防误抓。整体旋转时禁用选取。帧循环平滑手掌四元数，未限制手背翻转。

玩法一：捏合抓取后移动掌心控制拆解；仅当前引导要求旋转时，捏合后转腕触发已验证方向直接对齐，避免改变任意零件方向。玩法二：捏合抓取、平移、释放装配；张掌转动整体，所选构件不转动。

摄像头保持现有框内等比显示、骨架同映射。没有恢复手套指示。未向第三方API发送用户数据。
