# 榫卯抽取修复 v65

- 原因：v62 仅接入点击选择及整体旋转，鼠标拖动始终旋转 root，手势 GRAB 也只选择构件。
- 修复：按下构件进入轴向抽取；按下空白才旋转。抽取轴来自独立构件几何包围范围的最长轴，屏幕投影随当前视角变化，PC 与横屏手机共享比例。
- 鼠标释放时保留部分抽出位置，继续拖动可接着抽出。抽出足够距离后移出场景、更新计数与构件勾选；重复事件不能重复计数。
- 手势沿用用户第一次数据.zip 的 v33 控制器，将 GRAB / GRABBED 指针平移 / RELEASE 接到相同抽取函数。HOLD 不移动，长时间丢手、关闭摄像头、页面失焦或暂停时停止交互。
- 全部构件抽出才正式通关，保存 sunju-burr-complete-v1、图鉴报告及完整模型图片；选中、旋转、部分抽取不计通关。重新挑战恢复全部构件但保留历史通关记录。
- 当前是沿长轴抽离的游戏规则，没有恢复 CAD 装配约束，也未实现真实实体碰撞或工程拆解路径求解。三通源文件为真实几何；后续若要严格约束拆卸，需另行制定关卡运动路径。
- 通过 scripts/test-burr-extraction-v65.cjs 验证：三通 3 根、六木 6 根、鼠标实际拖动、空白旋转、部分抽取、重新开始、手势事件适配、横屏和图鉴联动。未使用摄像头实拍验证识别率。
