# 榫卯碰撞与旋转 v66

## 判定
- 从当前三通 CAD 网格与六木源网格的正交面坐标重建实体单元，射线奇偶法区分实木与缺口；不以整根零件外包围盒代替榫口。
- 每个实体单元随零件中心、位置、四元数形成 OBB，采用 15 分离轴测试；外包围范围仅作粗筛。
- 平移每步不超过 0.035 场景单位、旋转每步不超过 0.75°，遇碰撞后细分定位到最后可接受姿态；当前模型接触容差为 0.001 场景单位。属于运动约束与碰撞检测，不是含重力、质量、冲量的刚体动力学。
- 顺序由当前几何阻挡关系决定，不使用按编号强制解锁。移开活榫后，其他件的合法运动范围即时改变。
- 只有整个构件越过其余装配的外部范围才记抽出；最后一根仍需移出原装配中心。碰撞、仅旋转和部分位移不计完成。

## 操作
- 鼠标拖动零件：按屏幕拖动方向选择当前零件的局部移动轴。拖动空白：旋转整体视角。
- “旋转零件”或 Shift+拖动：绕长轴或下拉框选定的局部 X/Y/Z 轴旋转，旋转同样受碰撞限制。
- 手势仍使用用户提供的 v33 控制器与姿态映射。GRAB 后掌心平移控制位置，手掌基底的四元数变化控制单件朝向；与鼠标共用受碰撞限制的姿态提交函数。被挡住时重新锚定，避免累积跳动。
- 线索探测当前可移动或可旋转的构件，先显示合法动作。没有找到单件可行动作时明确显示互锁，不跳过碰撞。
- 通关报告标记 rulesVersion=collision-v66。v65 历史通关记录保留，不自动删除。

## 验证与限制
- 六木源模型已验证完整六件拆解路径：先移出第 3 根，再逐步给后续构件让位；错误先手被挡住，路径中每一步无实体重叠。
- 用窄口测试结构验证直拉阻挡、旋转后通过，验证高速拖动不直接穿过阻挡体、重复抽出不重复计数、鼠标及手腕姿态适配、横屏比例。
- 用户三通模型在当前装配下，单件沿三轴直移及绕中心三轴旋转均未发现可验证的第一步；没有据此强行穿模或更改源零件几何。需用户提供实际拆解步骤，进一步确认是否有协同移动或其他转动支点。
- 不支持任意曲面网格的精确凹体分解；当前碰撞几何来自已验证的正交榫木网格。
